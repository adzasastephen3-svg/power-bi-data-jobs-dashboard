# Data Jobs Dashboard – Power BI

## Overview
I developed an interactive Power BI dashboard to explore and analyze data-related job opportunities, focusing on job titles, salaries, work arrangements, and employment benefits.

## Features and Visualizations Added

### 1. Main Dashboard
- **Job Title Slicer:** Added a filter to allow users to explore specific data job positions.
- **Count of Jobs Card:** Displays the number of jobs based on the selected filters.
- **Median Yearly Salary Card:** Provides a salary overview for yearly compensation.
- **Median Hourly Salary Card:** Highlights hourly salary information.
- **Bar Chart:** Compares job titles, work-from-home availability, and hourly salary information.
- **Data Jobs Table:** Displays job-related information, including:
  - Job titles.
  - Number of jobs.
  - Number of skills.
  - Work-from-home information.
  - Salary rates.
  - Job posting dates.

### 2. Drill-Through Dashboard
Created a separate drill-through page to provide additional insights into selected job positions.

The page includes:

- **Job Title Card:** Displays the selected job title.
- **Donut Chart – Job Schedule Types:** Shows the distribution of different employment schedule types.
- **Pie Chart – Health Insurance:** Visualizes job health insurance information.
- **Pie Chart – Search Location:** Shows the distribution of job opportunities by country/location.
- **Yearly Salary Gauge:** Displays yearly salary statistics, including minimum, maximum, average, and median salary.
- **Hourly Salary Gauge:** Displays hourly salary statistics, including minimum, maximum, average, and median salary.

### 3. Interactive Functionality
- Implemented drill-through navigation between dashboard pages.
- Added job-title-based filtering.
- Enabled visual interactions so that selecting data points updates related charts.
- Included navigation buttons to improve dashboard usability.

## Key Insights the Dashboard Supports

The dashboard allows users to explore:

1. Salary differences across data-related job positions.
2. The availability of remote and work-from-home opportunities.
3. The distribution of employment schedule types.
4. Job opportunities across different countries.
5. Health insurance availability across job listings.
6. Differences between hourly and yearly salary ranges.

## Tools Used
- Microsoft Power BI
- Power BI Visualizations
- Interactive Filters and Slicers
- Drill-Through Functionality

## Conclusion
This project demonstrates the use of Power BI to build an interactive data jobs dashboard. It combines salary analysis, employment information, geographical distribution, and job benefits into a visual reporting experience.
